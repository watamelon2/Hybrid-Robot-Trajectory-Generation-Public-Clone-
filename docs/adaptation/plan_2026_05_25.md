## Headline already visible in the run

Cell 1 (`N_b = 5`), mid-cell at ~15:25 PT (53/60 rollouts):

- **80 % in-bank** (demos 0–4 — bank contains their own demos as
  1-NN candidates)
- **0 % out-of-bank** (demos 5–19 — bank's 1-NN is the
  wrong-trajectory mode)
- 23 % overall, on track for a ~25-30 % final rate

This is **the variance-reduction-by-mode-anchoring story** in its
sharpest form: $\rho(\bar\tau) \gg 1$ when the bank covers the
state's mode; $\rho \to 1$ when it doesn't. The 80 % / 0 %
bimodality is much steeper than my §5 spec prediction
($\sim\!30\%$ overall — that was averaged over both populations).
The crisp split substantiates Theorem 1' Corollary 1 more
directly than I had expected.

The **knee at $N_b{=}20$** is the key falsification target. If
the curve continues to climb past N_b=50 / 100, the retrieval is
**not** bank-saturation limited and Corollary 1's mode-anchoring
story needs revision.

## Decision points along the way

1. **If `N_b=10` succ < 35 %**: the bimodality is tighter than
   predicted; the curve will saturate later. Reframe spec 03's §5
   plot as "in-bank coverage" rather than "bank size."
2. **If `N_b=200` succ ≠ 73.8 % ± 5 pp**: reproduction sanity
   broken; investigate. The canonical headline is at exactly this
   operating point with seed=0, so we should reproduce it.
3. **If parallel branch-cleanup conflicts with my edits**: defer
   any new code changes until the cleanup settles. The slates can
   keep running regardless (their processes have already loaded
   the code into memory).
4. **If a worker propagation defect resurfaces in cost-time after
   the fix**: triage by checking `_worker_init`'s log output for
   the perturbation kwargs (add a print statement). Verify with a
   single-cell smoke at $\Delta x{=}+20$ cm, demo_0 alone — should
   succeed in canonical but fail under perturbed cost.
